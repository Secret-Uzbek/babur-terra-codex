> Human-facing historical research branch around Babur, Baburnama, continuity,
> memory, and civilizational reading through the wider Terra / FMP ecosystem.

## Layer role

This repository is a human-facing research branch.

It should hold:

- Babur-related research materials;
- historical and civilizational interpretation;
- public-facing branch documents and source maps;
- branch-level release, citation, and audit surfaces.

It should not become:

- a generic theory hub;
- a raw archive sink;
- a donor governance repository;
- a broken symbolic shell with almost no human entry.

## Reading path

1. `README.md`
2. `CITATION.cff`
3. `STANDARDS.md`
4. `LANGUAGE-STRATEGY.md`
5. branch-specific research files

## Ecosystem position

- `FMP-CENTRAL-REPO` — central public hub
- `women-made-central-asia` — companion human-facing branch
- `ziyarat-terra-corpus` — sacred and pilgrimage discourse branch
- `navoiy-terra-corpus` — literary corpus branch
- `terra-legal` — donor governance and standards

## Operating rule

This repository must remain readable for humans first.

Its role is to expose a distinct branch of meaning, not to imitate the whole
ecosystem in miniature.
